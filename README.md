# 수면부채 계산 (가칭)

본인에게 얼마나 수면이 부족한지 눈으로 확인하고 조절하도록 도와주는 안드로이드 앱입니다.

갤럭시 워치나 핏이 잰 수면을 Health Connect로 가져와 **최근 7일의 수면 부채**를 계산하고, 요일별 기상 목표에 맞춰 **오늘 밤 몇 시에 자면 좋을지** 알려 줍니다. 서버나 로그인 없이 휴대폰 안에서만 동작합니다.

> 폴더 이름(`HealthConnectSleepPOC`)은 처음 "Health Connect로 수면 데이터를 읽을 수 있는지" 확인하던 POC에서 시작해 남아 있는 이름입니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 첫 실행 튜토리얼 | 처음 한 번만 3장으로 안내합니다: 수면 부채란? · 워치 기록 불러오기 · 이렇게 써요 |
| 수면 부채 | 첫 화면 맨 위. 최근 7일 기준이며 "계산 내역 보기"로 날짜별 근거를 볼 수 있습니다 |
| 최근 7일 그래프 | 목표선(점선)과 함께 표시하고, 제목 아래에 평균 수면과 기록된 일수를 보여 줍니다 |
| 그날 상세 | 그래프 막대를 누르면 그날 기록이 나오고, 같은 막대를 다시 누르면 닫힙니다. 직접 넣은 기록은 여기서 지울 수 있습니다 |
| 오늘 밤 추천 | 취침 시각 · 목표 기상 · 총 수면만 보이고, 이유는 "추천 이유 보기"로 펼칩니다 |
| 수면 직접 추가 | 워치를 안 차고 잔 날이나 밤샌 날을 최근 7일 안에서 넣습니다. 12시간 이상이면 저장 전에 한 번 확인합니다 |
| 수면 목표 | 목표 수면 시간을 `07:30`처럼 숫자로 입력(4~12시간)하고, 요일별 기상 목표를 정합니다. 바꾼 채 저장하지 않고 닫으면 확인 창이 뜹니다 |
| 동기화 표시 | 새로고침 중에는 아이콘이 돌고, 부채 카드 위에 "방금 업데이트" · "12분 전 업데이트"를 보여 줍니다. 실패하면 빨간 글씨로 알려 줍니다 |
| 홈 위젯 | 오늘 밤 추천 취침과 수면 부채를 보여 줍니다. 마지막 업데이트가 실패했거나 6시간 넘게 지나면 맨 윗줄에 ⚠ 경고가 나옵니다 |
| 자동 동기화 | 앱이 꺼져 있어도 약 1시간마다 새 기록을 읽습니다 (백그라운드 읽기 권한이 있을 때만) |

## 수면 부채 계산 방식

```
수면 부채 = Σ (목표 수면 − 그날 수면) × 가중치      (합이 0보다 작으면 0 = "없음")
가중치    = 오늘 7/7, 어제 6/7, … , 6일 전 1/7
```

- 수면은 **일어난 날짜**에 묶이고, 같은 날의 낮잠은 합쳐집니다.
- 목표보다 더 잔 날은 부채를 줄입니다.
- **기록이 없는 날은 계산에서 빠집니다.** 밤샘으로 기록한 날은 0시간으로 계산됩니다.
- 수면 시간은 잠든 시각부터 일어난 시각까지 전체입니다. 중간에 깬 시간은 빼지 않습니다.
- 가중치 방식은 아직 확정되지 않았습니다 (아래 "남은 일" 참고).

## 데이터는 어디에 저장되나

| 데이터 | 저장 위치 |
|---|---|
| 워치 수면 기록 | Health Connect에서 읽어 오고, 지난 기록을 계속 보도록 앱 안(`sleep_archive.json`)에 사본을 보관합니다. 처음에는 최대 2년치, 이후에는 최근 14일을 다시 읽습니다 |
| 직접 추가한 수면 | Health Connect에 저장합니다 ("직접 입력"으로 표시) |
| 밤샘 기록 · 목표 · 튜토리얼 여부 · 동기화 시각 | 앱 안에만 저장합니다 |

수면 데이터를 외부 서버로 보내지 않습니다. 휴대폰의 Android 백업이 켜져 있으면 Google 계정 백업에 포함될 수 있습니다.

## 실행 전 준비물

1. **실제 안드로이드 기기**: 삼성 헬스 실데이터가 필요해서 에뮬레이터로는 제대로 확인할 수 없습니다
2. 그 기기에 **삼성 헬스 앱**이 있고, 갤럭시 워치나 핏의 수면 기록이 있을 것
3. **Health Connect**: Android 14 이상은 기본 내장, 그 아래는 Play 스토어에서 설치
4. 삼성 헬스 설정의 Health Connect 메뉴에서 **"수면" 공유가 켜져 있을 것**
5. **Android Studio**

## 여는 방법

1. Android Studio에서 `File > Open` → 이 폴더 선택
2. Gradle Sync가 끝나면 상단에서 실제 기기를 고르고 Run(▶)
3. 첫 실행 튜토리얼이 끝나면 Health Connect 권한 창이 뜹니다
   - **수면 읽기 · 쓰기**: 기록을 보고 직접 추가하는 데 필요
   - **과거 데이터 읽기**: 30일보다 오래된 기록까지 가져올 때 필요
   - **백그라운드 읽기**: 앱이 꺼져 있을 때 위젯을 최신으로 유지하는 데 필요
4. 오른쪽 위 설정(⚙)에서 목표 수면 시간과 요일별 기상 목표를 정하면 오늘 밤 추천이 나옵니다

### 빌드 참고

- 프로젝트 기준: AGP 8.5.2 · Kotlin 1.9.24 · Gradle 8.7 · compileSdk/targetSdk 34 · minSdk 26
- 저장소에 `gradlew`는 없습니다. Android Studio로 열거나, 설치된 Gradle 8.7로 빌드합니다.
- **Gradle 8.7은 Java 25에서 돌지 않습니다.** 명령줄로 빌드할 때는 `JAVA_HOME`을 JDK 17~21로 맞춰 주세요. Android Studio에서는 Settings → Build Tools → Gradle → Gradle JDK에서 고릅니다.

```bash
JAVA_HOME=<JDK 17~21 경로> gradle assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

## 데이터가 안 보일 때 체크리스트

- 삼성 헬스 앱에 실제로 최근 수면 기록이 있는지 먼저 확인
- 삼성 헬스 설정의 Health Connect 메뉴에서 "수면" 항목이 켜져 있는지 확인
- Health Connect 앱 → "앱 및 기기"에 Samsung Health가 데이터 제공자로 연결되어 있는지 확인
- 삼성 헬스 → Health Connect 동기화는 바로 되지 않을 수 있습니다. 몇 분 뒤 새로고침
- 위젯에 "⚠ ○시간 전 기록"이 자주 보이면 Health Connect에서 이 앱의 **백그라운드 읽기** 권한이 켜져 있는지 확인

## 남은 일

- 기록이 0건일 때 "아직 기록이 없어요"와 연결 방법 안내 (지금은 부채 칸에 "없음"이 떠서 잘 자는 것처럼 보임)
- 수면 부채 가중치 방식과 기록 없는 날을 세는 방법 확정
- 한 달 동안 부채가 줄었는지 볼 수 있는 기록 (성공 기준)
- 취침 시각 알림
- 앱 아이콘 (지금은 안드로이드 기본 아이콘)

자세한 검토 내용은 [`개선-정리.md`](개선-정리.md)에 있습니다.
