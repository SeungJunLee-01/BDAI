# HealthConnectSleepPOC

갤럭시 워치/핏으로 측정된 수면 데이터를 Health Connect를 통해 안드로이드 앱에서 읽어올 수 있는지 검증하기 위한 최소 기능 POC입니다. 디자인은 신경 쓰지 않았고, 버튼 1개 + 결과 리스트만 있습니다.

## 실행 전 준비물

1. **실제 안드로이드 기기** (에뮬레이터 X — 삼성 헬스 실데이터가 필요해서 실기기로 테스트해야 합니다)
2. 그 기기에 **삼성 헬스 앱**이 설치되어 있고, 갤럭시 워치/핏의 수면 데이터가 기록되어 있을 것
3. **Health Connect 앱**이 설치되어 있을 것 (Android 14 이상은 기본 내장, 그 이하 버전은 Play 스토어에서 "Health Connect" 검색해 설치)
4. 삼성 헬스 앱에서 **Health Connect 연동/권한이 켜져 있는지** 확인
   - 삼성 헬스 → 설정 → Health Connect 관련 메뉴에서 "수면" 데이터 공유가 허용되어 있어야 합니다.
5. **Android Studio** (Giraffe 이상 권장)

## 여는 방법

1. Android Studio에서 `File > Open` → 이 `HealthConnectSleepPOC` 폴더 선택
2. Gradle Sync가 자동으로 시작됩니다. Gradle 버전/AGP 버전을 올리라는 안내가 뜨면 그대로 따라가도 됩니다 (버전 충돌 방지용으로 프로젝트에 명시한 버전은 하나의 기준점일 뿐입니다).
3. 상단에서 실제 기기를 선택하고 Run 버튼(▶) 클릭
4. 앱에서 "수면 데이터 불러오기" 버튼 클릭
   - 처음 실행 시 Health Connect 권한 요청 화면이 뜹니다 → 수면 데이터 읽기 허용
   - 허용 후 최근 7일간의 수면 세션이 리스트로 표시됩니다

## 데이터가 안 보일 때 체크리스트

- 삼성 헬스 앱을 열어서 실제로 최근 수면 기록이 있는지 먼저 확인
- 삼성 헬스 → Health Connect 동기화 설정에서 "수면" 항목이 켜져 있는지 확인
- Health Connect 앱을 직접 열어서 "앱 및 기기" 탭에 Samsung Health가 데이터 제공자로 연결되어 있는지 확인
- 동기화가 즉시 안 될 수 있다고 삼성 공식 문서에 명시되어 있음 (기기 상태에 따라 지연 가능) → 몇 분 기다렸다가 재시도

## 다음 단계 (이 POC가 성공하면)
